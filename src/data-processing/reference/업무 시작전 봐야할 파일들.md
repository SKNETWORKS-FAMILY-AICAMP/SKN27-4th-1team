# 업무 시작전 봐야할 파일들

## 내 업무 정의

내가 맡은 업무는 **크롤링된 위키피디아 데이터에서 본문 텍스트를 정리하고, 각 문서를 대표하는 핵심 키워드를 뽑는 전처리 작업**이다.

쉽게 말하면, 지금 데이터에 들어 있는 영어/한국어 본문에서 분석에 방해되는 문자와 노이즈를 제거한 뒤, 각 인물, 사건, 괴담, 민간신앙 개념을 설명할 수 있는 대표 키워드를 새 컬럼으로 만드는 일이다.

이번 업무의 핵심은 두 가지다.

1. **본문 정리**
   - `#`, `/`, `[ ]`, `^`, 각주 번호, 불필요한 기호처럼 분석에 방해되는 내용을 제거한다.
   - 무엇을 제거했는지 기록해야 한다.
   - 정리 전 텍스트와 정리 후 텍스트를 비교할 수 있어야 한다.

2. **키워드 추출**
   - 각 문서의 특징을 보여주는 대표 단어 또는 짧은 문장을 뽑는다.
   - 키워드를 어떤 기준으로 뽑았는지 설명할 수 있어야 한다.
   - 단순히 많이 나온 단어가 아니라, 문서의 주제와 연결되는 단어를 골라야 한다.

최종적으로 만들면 좋은 컬럼은 다음과 같다.

```text
cleaned_text
removed_patterns
keywords
keyword_basis
```

즉, 이번 업무는 다음 한 문장으로 정리할 수 있다.

> 위키피디아에서 크롤링한 구마/빙의/무속 관련 데이터를 RAG나 분석에 쓰기 좋게 본문을 정제하고, 문서별 대표 키워드를 추가하는 작업이다.

이번 업무는 크롤링 자체보다 **크롤링된 텍스트 데이터를 전처리하고, 중요한 키워드를 뽑는 작업**에 가깝다.

따라서 크롤링 수업 파일만 보기보다는, 데이터 클리닝, pandas, NLP 전처리 파일을 같이 참고하는 것이 좋다.

- `replace`, 정규표현식, 문자열 정리 사용
- 어떤 문자를 제거했는지 기록
- 정리 전 텍스트와 정리 후 텍스트를 비교할 수 있게 만들기

만들면 좋은 컬럼:

- `cleaned_text`
- `removed_patterns`

### 2. 중요한 키워드 추출

해야 할 일:

- 각 인물, 사건, 괴담, 민간신앙 개념을 대표하는 단어 또는 짧은 문장 추출
- 키워드 추출 기준을 설명할 수 있어야 함
- 단순히 아무 단어나 뽑는 것이 아니라, 해당 문서의 특징을 보여주는 단어를 뽑기

만들면 좋은 컬럼:

- `keywords`
- `keyword_basis`

## 정리

이번 업무는 다음 흐름으로 진행하면 된다.

```text
크롤링된 JSON/CSV 읽기
→ 본문 텍스트 선택
→ 필요 없는 문자 제거
→ 제거한 규칙 기록
→ cleaned_text 컬럼 생성
→ 중요한 키워드 추출
→ keywords 컬럼 생성
→ 추출 기준을 keyword_basis 컬럼에 기록
→ 전처리된 CSV/JSON 저장
```

가장 중요한 것은 두 가지다.

1. **무엇을 제거했는지 설명할 수 있어야 한다.**
2. **키워드를 어떤 기준으로 뽑았는지 설명할 수 있어야 한다.**
