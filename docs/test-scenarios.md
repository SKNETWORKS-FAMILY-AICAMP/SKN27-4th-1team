# 테스트 시나리오

이 문서는 현재 구현 기준으로 수동 테스트와 자동 테스트에서 확인해야 할 주요 흐름을 정리한다.

## 1. 기록 열람실 챗봇

| ID | 시나리오 | 사전 조건 | 테스트 절차 | 기대 결과 |
|---|---|---|---|---|
| ARCH-01 | 첫 검색어 자동 실행 | 서버 실행 상태 | 첫 화면에서 검색어 입력 후 이동 | `/archive/chatbot/?q=...`로 이동하고 첫 메시지가 자동 처리된다. |
| ARCH-02 | 후보 기록 검색 | 검색 가능한 원천 데이터 존재 | 챗봇에 괴담 소재 입력 | `/archive/api/search/` 응답에 `results`와 `llm_response`가 포함된다. |
| ARCH-03 | 후보 목록 선택 | 검색 결과 표시 상태 | 번호 또는 제목 일부 입력 | 선택한 기록 기준으로 `/archive/api/rewrite/`가 호출된다. |
| ARCH-04 | 익명 게시글형 괴담 생성 | 선택 기록 존재 | 후보 기록 선택 | 응답 본문이 소설체보다 커뮤니티 체험담 형태에 가깝게 표시된다. |
| ARCH-05 | 평가 실패 후 재작성 | 생성 결과가 평가 기준 미달 | 문학체 표현 또는 직접 공포 표현이 포함된 결과 유도 | 자동 패널티가 반영되고 최대 1회 재작성된다. |
| ARCH-06 | 낭독 요청 | 재구성 괴담 생성 완료 | `읽어줘` 입력 | 저장된 `last_tts_text` 기준으로 `/archive/api/tts/` 스트림이 재생된다. |
| ARCH-07 | 낭독 중지 | 낭독 재생 중 | `멈춰`, `중지`, `정지`, `그만` 입력 | 현재 TTS와 배경음이 즉시 중지된다. |
| ARCH-08 | 기록 보관 | 로그인 및 선택 기록 존재 | `저장` 또는 `save` 입력 | `/accounts/api/bookmark/add/` 호출 후 중복 없이 보관된다. |

## 2. 금기 자료실

| ID | 시나리오 | 사전 조건 | 테스트 절차 | 기대 결과 |
|---|---|---|---|---|
| TABOO-01 | 금기 목록 조회 | Superstition 데이터 존재 | 금기 자료실 진입 | 전체 목록 API 결과가 화면에 표시된다. |
| TABOO-02 | 금기 검색 | Superstition 데이터 존재 | 키워드 검색 | 내용, 분류, 지역, 출처, 번호 기준 매칭 결과가 표시된다. |
| TABOO-03 | 오늘의 금기 | Superstition 데이터 존재 | 오늘의 금기 실행 | 같은 날짜에는 같은 금기 항목이 반환된다. |
| TABOO-04 | 금기 상세 | 목록 결과 존재 | 특정 항목 선택 | 선택한 ID의 상세 내용이 표시된다. |

## 3. 신규 기록실

| ID | 시나리오 | 사전 조건 | 테스트 절차 | 기대 결과 |
|---|---|---|---|---|
| GEN-01 | 조건 기반 생성 | LLM 설정 가능 | 지역, 장소, 괴이 유형, 금기 등을 입력 후 생성 | 제목과 본문이 JSON으로 정규화되어 화면에 표시된다. |
| GEN-02 | 생성 실패 처리 | LLM 오류 상황 | 생성 API 호출 실패 유도 | 서버가 중단되지 않고 오류용 제목과 본문을 반환한다. |
| GEN-03 | 창작담 게시 | 로그인 및 생성 결과 존재 | 생성 결과 게시 | 열린 게시판에 `CREATION` 카테고리 글로 저장된다. |

## 4. 열린 게시판

| ID | 시나리오 | 사전 조건 | 테스트 절차 | 기대 결과 |
|---|---|---|---|---|
| POST-01 | 목록 조회 | 게시글 존재 | 목격담/창작담 탭 조회 | 카테고리별 목록이 표시된다. |
| POST-02 | 게시글 검색 | 게시글 존재 | 제목, 지역, 본문 키워드 검색 | 매칭 게시글 목록이 반환된다. |
| POST-03 | 게시글 작성 | 로그인 상태 | 제목, 지역, 본문, 카테고리 입력 | 새 게시글이 생성된다. |
| POST-04 | 창작담 좋아요 | 로그인 및 창작담 존재 | 좋아요 버튼 클릭 | 사용자별로 좋아요가 토글되고 카운터가 갱신된다. |
| POST-05 | 작성자 권한 | 로그인 및 본인 글 존재 | 본인 글 수정/삭제, 타인 글 수정/삭제 시도 | 본인 글은 성공하고 타인 글은 403으로 차단된다. |

## 5. 계정과 보관함

| ID | 시나리오 | 사전 조건 | 테스트 절차 | 기대 결과 |
|---|---|---|---|---|
| ACC-01 | 회원가입 | 미로그인 상태 | 유효한 회원가입 폼 제출 | User가 생성되고 자동 로그인된다. |
| ACC-02 | 로그인 실패 | 계정 없음 또는 비밀번호 불일치 | 잘못된 로그인 폼 제출 | 폼 오류가 표시되고 세션이 생성되지 않는다. |
| ACC-03 | 인증 필요 API | 미로그인 상태 | 북마크, 글 작성, 좋아요 API 호출 | 로그인 화면 또는 401 JSON 응답을 반환한다. |
| ACC-04 | 마이페이지 | 로그인 및 사용자 데이터 존재 | 마이페이지 진입 | 프로필, 작성 글, 보관 목록이 사용자 기준으로 표시된다. |

## 6. 지역 정보실

| ID | 시나리오 | 사전 조건 | 테스트 절차 | 기대 결과 |
|---|---|---|---|---|
| REG-01 | 지역 목록 | Neo4j 연결 가능 | 지역 정보실 진입 | Region 및 Origin 기반 지역 목록과 연결 수가 표시된다. |
| REG-02 | 지역별 도시/스토리 | Neo4j 연결 가능 | 특정 지역 선택 | 도시 하위 스토리 또는 지역 직속 스토리 목록이 표시된다. |
| REG-03 | 스토리 상세 | 스토리 ID 존재 | 스토리 선택 | 전체 본문이 표시된다. |
| REG-04 | Neo4j 실패 처리 | Neo4j 연결 불가 | 지역 API 호출 | 서버 중단 없이 빈 결과 또는 오류 상태가 반환된다. |

## 7. 자동 테스트

| ID | 대상 | 검증 내용 |
|---|---|---|
| AUTO-01 | `extract_story_from_model_response()` | LLM JSON 응답에서 `new_story` 본문만 추출한다. |
| AUTO-02 | `build_generation_prompt()` | 생성 프롬프트가 익명 커뮤니티 게시글 방향과 `new_story` 출력을 요구한다. |
| AUTO-03 | `build_revision_prompt()` | 재작성 프롬프트가 문학체 제거와 게시글스러움을 우선한다. |
| AUTO-04 | `apply_automatic_penalties()` | 문학체 표현, 게시글 말투 부족, 회상문식 도입부가 점수 상한을 낮춘다. |
| AUTO-05 | `is_evaluation_passed()` | 9개 세부 점수와 최종 점수 90점 이상 조건을 함께 확인한다. |
