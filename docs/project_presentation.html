01. Project Overview

프로젝트 개요

Django 기반의 괴담 및 금기 아카이브 플랫폼으로, 서비스 핵심 데이터는 PostgreSQL에 저장하고 지역·장소·괴담 관계는 Neo4j로 탐색합니다. LLM을 연동해 사용자가 직접 새로운 괴담을 창작하고 공유할 수 있도록 구성했습니다.

괴담 아카이브

검증된 괴담, 괴이 존재, 금기 데이터를 검색하고 열람합니다.

생성형 콘텐츠

지역, 장소, 금기, 발생 조건을 입력해 AI 괴담을 생성하고 평가 흐름까지 연결합니다.

커뮤니티

목격담과 창작담을 작성하고, 본인 글을 수정·삭제할 수 있습니다.

02. Background & Goals

개발 배경과 프로젝트 목표

해결하고자 한 문제
  • 지역 괴담과 금기 정보가 파편화되어 탐색이 어려움
  • 괴담, 장소, 괴이의 관계를 텍스트만으로 파악하기 어려움
  • 괴담 창작 진입 장벽이 높음
  • 콘텐츠 소비에 어울리는 몰입형 UI가 부족함
구현 목표
  • Django 기반 사용자 인증, 마이페이지, 열린 게시판 구현
  • PostgreSQL 기반 괴담/금기 데이터 저장과 검색 제공
  • Neo4j 기반 지역-장소-괴담 관계 탐색 구현
  • Groq/Ollama 기반 LLM 생성과 RAGAS 평가 흐름 구성
  • 터미널형 UI, 글리치, 음향 효과로 몰입감 강화
03. Concept

오래된 괴담 기록소에 접속하는 경험

괴이바는 단순한 정보 검색 사이트가 아니라, 사용자가 금지된 기록을 열람하는 듯한 분위기를 느끼도록 설계한 괴담 아카이브 서비스입니다.

접속 경험

사용자가 일반 웹사이트가 아니라 오래된 기록 장치에 접속한 듯한 첫인상을 목표로 했습니다.

기록소 세계관

기록 열람실, 금기 자료실, 신규 기록실처럼 페이지 이름부터 아카이브 콘셉트에 맞췄습니다.

탐색 동기

괴담을 단순히 읽는 것이 아니라, 금지된 자료를 찾아 들어가는 흐름으로 서비스 몰입을 유도했습니다.

04. Service Flow

서비스 핵심 흐름

기록소 접속 괴담·금기 탐색 지역 관계 조회 AI 신규 기록 생성 공유·보관·관리
탐색 중심 흐름

사용자는 메인 화면에서 기록소에 접속한 뒤 기록 열람실, 금기 자료실, 지역 정보실을 통해 괴담과 금기 데이터를 탐색합니다.

참여 중심 흐름

탐색한 세계관을 바탕으로 신규 기록실에서 AI 괴담을 생성하고, 열린 게시판에 공유하거나 나의 보관함에서 관리합니다.

05. System Flow

시스템 흐름

요청 처리 흐름
  • 브라우저 요청을 config/urls.py와 각 app/urls.py에서 라우팅
  • views.py가 페이지 렌더링과 JSON API 응답을 처리
  • services.py가 DB 조회, LLM 호출, Neo4j 조회 로직을 담당
데이터 처리 흐름
  • PostgreSQL: 사용자, 게시글, 금기, 생성 결과, 보관함
  • Neo4j: 국가, 지역, 장소, 괴담, 신화 존재 관계 탐색
  • Groq/Ollama: 챗봇 응답, 신규 괴담 생성, 평가 보조
accounts archive generator post regions Groq Ollama Docker
