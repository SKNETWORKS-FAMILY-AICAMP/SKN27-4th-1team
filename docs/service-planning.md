# 괴담 아카이브 서비스 기획서


## 1. 프로젝트 개요

전 세계의 괴담, 도시전설, 금기, 목격담을 수집하고 사용자가 직접 새로운 괴담을 생성하거나 제보할 수 있는 웹 서비스입니다.

기본 방향은 단순 게시판이 아니라, 사용자가 오래된 비밀 기록소 또는 괴담 데이터베이스에 접속한 듯한 체험을 제공하는 것입니다. 화면 디자인은 어두운 배경, 붉은 조명, 터미널풍 인터페이스, 깜빡임 효과, 공포 사운드 등을 활용해 몰입감을 강화합니다.

## 2. 기획 의도

괴담 콘텐츠는 단순히 읽는 것보다 “내가 직접 찾아낸다”, “내가 제보한다”, “내가 만들어낸다”는 참여 경험이 중요합니다.

이 서비스는 사용자가 괴담을 소비하는 데서 끝나지 않고, LLM을 활용해 자신만의 괴담을 만들고 저장하며, 다른 사용자의 목격담과 지역별 괴이 정보를 탐색할 수 있도록 설계합니다.

## 3. 핵심 콘셉트

- 세계 각지의 괴담과 금기를 수집하는 아카이브
- 사용자의 입력으로 괴담을 생성하는 AI 기반 창작 도구
- 목격담을 제보하고 열람하는 커뮤니티
- 지역별 괴담 분포를 탐색하는 지도형 콘텐츠
- 공포 분위기를 강화하는 체험형 UI

현재 화면 디자인에서는 `괴이 실록`, `실록관`, `금기록`, `괴이제조소` 같은 명칭이 사용되고 있으나, 이는 초기 콘셉트명으로 보고 추후 서비스명과 메뉴명은 변경 가능하게 둡니다.

## 4. 주요 사용자

- 괴담, 도시전설, 미스터리 콘텐츠에 관심 있는 사용자
- 직접 괴담을 창작하거나 AI의 도움을 받아 이야기를 만들고 싶은 사용자
- 지역별 괴담, 금기, 목격담을 찾아보고 싶은 사용자
- 자신이 겪은 이상한 경험을 제보하고 기록하고 싶은 사용자

## 5. 주요 화면 구성

### 5.1 시작 화면

사용자가 서비스에 처음 진입하는 화면입니다.

- 어두운 병실 이미지와 붉은 조명 전환 연출
- “기록 열기” 형태의 진입 버튼
- 첫 문장을 입력해 검색 또는 챗봇 흐름으로 이동
- 공포 사운드와 화면 깜빡임으로 몰입감 제공

### 5.2 아카이브/검색 화면

괴담, 지역명, 목격담 키워드를 입력해 관련 기록을 조회하는 화면입니다.

- 검색어 입력
- 챗봇 또는 터미널 로그 형태의 응답
- 추후 LLM 기반 검색 요약과 추천 기능 연결 가능

### 5.3 금기/규칙 탐색 화면

지역별 또는 주제별 금기를 확인하는 화면입니다.

- 지역별 금기
- 이름 관련 금기
- 밤길 관련 금기
- 물가 관련 금기
- 산, 숲, 폐가, 제사 등 테마별 금기
- 위험도 등급 표시

### 5.4 괴담 생성 화면

LLM을 활용해 사용자가 입력한 조건으로 괴담을 생성하는 화면입니다.

입력 요소:

- 지역
- 장소
- 괴이 유형
- 금기
- 시간
- 발생 조건
- 결말

출력 요소:

- 생성된 괴담 초안
- 저장 여부
- 재생성 또는 수정 요청
- 나의 기록으로 저장

### 5.5 목격담 게시판

사용자들이 직접 겪은 경험이나 창작 목격담을 등록하는 커뮤니티 화면입니다.

- 제목, 지역, 내용 입력
- 목격담 목록 조회
- 조회수 표시
- 추후 댓글, 추천, 신고, 공개/비공개 설정 확장 가능

### 5.6 지역 지도 화면

세계 지도 또는 지역 지도를 기반으로 괴담 분포를 탐색하는 화면입니다.

- 지도 확대/축소
- 지역별 괴담 수 표시
- 위험도 또는 괴이 유형별 필터
- 특정 지역 선택 시 관련 괴담 목록 표시

### 5.7 나의 기록 화면

로그인한 사용자의 활동 기록을 관리하는 화면입니다.

- AI로 생성한 괴담 목록
- 저장한 초안과 완성본
- 작성한 목격담
- 공개/비공개 기록
- 상세 내용 펼쳐보기

### 5.8 로그인/회원가입 화면

사용자 인증을 위한 화면입니다.

- 로그인
- 회원가입
- 사용자별 기록 저장
- 추후 소셜 로그인 또는 익명 기록자 기능 검토 가능

## 6. 핵심 기능

## 6.1 괴담 검색

사용자가 입력한 키워드, 지역명, 괴이 유형을 기반으로 관련 괴담을 검색합니다.

초기에는 데이터베이스 기반 검색으로 구현하고, 이후 LLM을 활용해 유사한 괴담 추천이나 검색 결과 요약을 제공할 수 있습니다.

## 6.2 AI 괴담 생성

사용자가 입력한 조건을 바탕으로 LLM이 괴담을 생성합니다.

예상 생성 방식:

- 짧은 괴담
- 실록체 기록문
- 목격담 형식
- 금기 위반 서사
- 지역 전설 형식

## 6.3 금기 데이터 조회

괴담 세계관의 핵심 소재가 되는 금기 데이터를 조회합니다.

금기는 단순 문장이 아니라 지역, 위험도, 유형, 관련 괴담과 연결되는 구조로 관리합니다.

## 6.4 목격담 제보

사용자가 직접 목격담을 작성하고 등록합니다.

기본 기능:

- 글 작성
- 글 목록 조회
- 글 상세 조회
- 글 수정/삭제

확장 기능:

- 댓글
- 추천
- 신고
- 비공개 제보
- AI 문체 보정

## 6.5 나의 기록 관리

사용자가 생성하거나 작성한 콘텐츠를 한 곳에서 확인합니다.

- 생성한 괴담
- 저장한 초안
- 게시한 목격담
- 비공개 기록

## 7. LLM 활용 방향

LLM은 서비스의 핵심 차별화 기능으로 사용합니다.

- 입력 조건 기반 괴담 생성
- 짧은 목격담을 긴 이야기로 확장
- 사용자가 쓴 글의 분위기 보정
- 지역과 장소에 어울리는 금기 추천
- 목격담의 괴이 유형 자동 분류
- 위험도 등급 자동 제안
- 기존 괴담과 유사한 기록 추천

초기 MVP에서는 `괴담 생성` 기능에 우선 적용하고, 이후 검색, 추천, 분류 기능으로 확장하는 것이 적절합니다.

## 8. MVP 범위

1차 구현 목표는 아래 범위로 잡습니다.

- 회원가입/로그인
- 괴담 생성
- 생성 결과 저장
- 목격담 작성/조회
- 금기 목록 조회
- 지역 지도 기본 화면
- 나의 기록 조회

MVP에서는 과도한 커뮤니티 기능보다 “AI 괴담 생성 + 기록 저장 + 목격담 제보” 흐름을 먼저 완성하는 것이 좋습니다.

## 10. 화면 디자인 방향

현재 디자인은 아래 분위기를 중심으로 구성되어 있습니다.

- 검정과 붉은색 중심의 공포 분위기
- 오래된 BBS 또는 터미널 같은 인터페이스
- 픽셀 폰트와 낮은 채도의 텍스트
- 화면 깜빡임, 노이즈, 글리치 효과
- 병실, 붉은 조명, 지도 이미지 등 시각적 공포 요소
- 버튼과 입력창도 일반 웹앱보다 기록 장치 또는 명령어 입력창처럼 보이도록 구성

추후 실제 구현에서도 이 분위기는 유지하되, 서비스명과 메뉴명은 확정 전까지 유연하게 바꿀 수 있도록 구조화하는 것이 좋습니다.

## 11. 개발 우선순위

1. 프로젝트 기본 구조 설계
2. 화면 디자인을 실제 프론트엔드 구조로 분리
3. 회원가입/로그인 구현
4. 괴담 생성 API 연동
5. 생성 결과 저장
6. 목격담 게시판 CRUD
7. 금기 데이터 조회
8. 나의 기록 조회
9. 지역 지도와 데이터 연결
10. UI 연출, 사운드, 접근성 보완

## 12. 한 줄 소개

세계 각지의 괴담과 금기를 수집하고, 사용자의 입력을 바탕으로 AI가 새로운 괴담을 생성해 주는 체험형 괴담 아카이브 서비스입니다.
